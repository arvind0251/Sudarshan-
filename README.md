# Telegram Member Adder & Spammer Reporter Bot

This bot allows you to manage Telegram accounts, add members to groups, and report spammers using multiple Telegram accounts.

## Features:
- Login with multiple Telegram accounts.
- Add members to Telegram groups.
- Report spammers on Telegram.
- Supports multiple batch processing for adding members.

## Requirements:
Before running the bot, you need to install the dependencies.

```bash
pip install -r requirements.txt
